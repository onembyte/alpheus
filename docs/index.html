Storage manager & cleanup engine for Linux (Omarchy / Arch) & macOS.

INSTALL
curl -fsSL https://onembyte.github.io/alpheus/install.sh | bash
COMMAND CHEAT-SHEET
COMMAND ACTION
alpheus Quick scan & summary of reclaimable storage tiers
alpheus -i Interactive keyboard TUI dashboard with batch safe cleanup
alpheus browse ~ Interactive directory drill-down tree explorer (ncdu-style)
alpheus top ~ Analyze and display top largest space consumers with meter bars
alpheus dupes ~ Find duplicate files using multi-tier SHA-256 matching
alpheus snapshot ~ Record a directory baseline snapshot
alpheus diff ~ Compare current disk state against snapshot to track storage growth
alpheus clean --all-safe Safely reclaim all regenerable build & package caches
alpheus schedule enable Enable automated weekly background cleanup (systemd user timer)
alpheus update Update Alpheus CLI binary in-place to the latest release
alpheus uninstall Completely and cleanly remove Alpheus, shell completions, and widget
INTEGRATION
• Omarchy OS: Top-bar Quickshell widget automatically deployed to ~/.config/omarchy/plugins/alpheus.
• Completions: Native auto-completions generated for bash, zsh, and fish.
• Safety: Strict denylist isolation outside $HOME + 5 GB Trash threshold rule.
• Clean Uninstall: Run alpheus uninstall or curl -fsSL https://onembyte.github.io/alpheus/uninstall.sh | bash.
